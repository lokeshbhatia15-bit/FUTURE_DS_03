# 📊 Marketing Funnel & Conversion Performance Analysis

## 📌 Project Overview

This project focuses on analyzing marketing funnel performance using Python-based Exploratory Data Analysis (EDA) and Power BI dashboarding techniques.

The objective of the project is to evaluate customer progression through different marketing funnel stages, identify conversion bottlenecks, measure campaign effectiveness, and optimize marketing ROI.

---

# 🎯 Project Objectives

- Analyze overall marketing funnel performance
- Identify customer drop-off points
- Measure marketing channel effectiveness
- Evaluate campaign performance
- Calculate business KPIs
- Build an interactive Power BI dashboard
- Generate actionable business recommendations

---

# 📂 Dataset Description

The dataset contains campaign-level marketing performance data with the following columns:

| Column Name | Description |
|---|---|
| Date | Campaign execution date |
| Channel | Marketing platform/channel |
| Campaign | Campaign name |
| Impressions | Number of users reached |
| Clicks | Number of clicks |
| Leads | Number of leads generated |
| Conversions | Successful conversions |
| Revenue | Revenue generated |
| Cost | Marketing expenditure |
| Device | Customer device type |
| Region | Geographic region |

# 📈 Key Performance Indicators (KPIs)

| KPI | Formula |
|---|---|
| CTR | Clicks / Impressions |
| Conversion Rate | Conversions / Leads |
| CPL | Cost / Leads |
| CAC | Cost / Conversions |
| ROI | (Revenue − Cost) / Cost |

# 💡 Key Insights

## 🔹 Conversion Bottleneck
A major customer drop-off occurs between:
> Leads → Conversions

## 🔹 High Performing Channels
- Google Ads generated highest revenue
- Instagram Ads showed strong conversion rates

## 🔹 Campaign Performance
- Festive Offer campaign generated highest leads
- Winter Sale contributed significant revenue

## 🔹 Device Insights
Mobile and tablet users generated the highest engagement.
